# ⚡ AnonGrief — Next-Gen Crack Archive & Loader Portal (Python / FastAPI)

Сайт-портал и репозиторий софта, кряков и читов под кодовым именем **AnonGrief**, выкачанный и воссозданный на основе оригинального фронтенда **mira.kim** (Tailwind 4, React SPA, Dark Mode, Before/After Slider) со встроенной **Админ-Панелью в Вебе и Telegram-Ботом**.

## ⚡ Быстрый запуск на твоём ПК в один клик

Просто дважды кликни по файлу:

Сайт откроется на `http://localhost:3000`. При запуске сервер автоматически поднимает **веб-сайт**, **API** и **Telegram-бота администратора**.

## 🚀 Деплой на Railway.com (Python)

Проект на 100% готов к развертыванию в облаке Railway:

1. Запушь проект в GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: AnonGrief mira.kim clone + TG admin bot"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/anongrief.git
   git push -u origin main
   ```
2. Открой [railway.com](https://railway.com) → **New Project** → **Deploy from GitHub repo**.
3. В переменных окружения при желании укажи `TG_BOT_TOKEN`, либо бот запустится по дефолту.
4. Railway автоматически поднимет и сайт, и Telegram-бота!
